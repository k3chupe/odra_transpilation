# odra-router — quantum transpiler project

Custom **Routing** and **Optimization** stages for the ODRA5 (IQM Adonis) 5-qubit star topology, compared against Qiskit 1.2.

## Setup

Requirements: Python 3.11+, qiskit 1.2.4 (pinned, see `tests/test_env.py`).

```bash
git clone git@github.com:k3chupe/odra_transpilation.git
cd odra_transpilation
python -m venv .venv
. .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -e ".[dev]"
pytest -q
```

On Windows (PowerShell), run commands one at a time instead of chaining with `&&`.

Conda alternative: `conda env create -f environment.yml && conda activate odra-router`, then `pip install -e ".[dev]"`.

Optional extras:

```bash
pip install -e ".[hardware]"   # IQM fake Adonis backend
pip install -e ".[ilp]"        # Gurobi for ILP baselines
pip install -e ".[analysis]"   # pandas/plotly for plots
```

`pytest -q` runs all tests; registered solvers are checked automatically by [tests/test_contract.py](tests/test_contract.py).

| Path | What's there |

| `tests/` | Pytest suite; `test_contract.py` runs every registered solver automatically |
| `benchmarks/` | `suite.json` — benchmark case definitions (edit this, not the committed CSVs) |

| `notebooks/` | Reference notebook `00_baseline.ipynb` |

## Visualization

The fidelity benchmark writes `results/benchmark-fidelity.csv`; to turn it into
charts and a summary:

```bash
pip install -e ".[analysis]"   # pandas + matplotlib
odra-router-bench-fidelity     # (re)generate results/benchmark-fidelity.csv
python visualize_results.py
```

Outputs:

- `plots/ideal_vs_solvers.png`, `plots/gap_to_ideal.png`, `plots/wins_comparison.png`,
  `plots/time_comparison.png`, `plots/quality_vs_time_tradeoff.png`, `plots/evaluations_comparison.png`
- `results_summary.md` at the repo root

The plots treat `exact_dp` as the ideal (a red reference line) and draw every
other solver as its distance from that optimum. The script only reads
`results/benchmark-fidelity.csv`; it never runs benchmarks itself, so run
`odra-router-bench-fidelity` first if the CSV is missing or stale.
